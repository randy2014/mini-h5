# 多媒体池子 · 需求说明书

> 版本：v1.0（需求定稿）
> 状态：**已实施并上线**（生产版本 `1e0f693`，2026-09-10）
> 相关文档：技术设计见 `docs/media-pool-design.md`；界面原型见 `docs/prototypes/media-pool-prototype.html`
> 关联模块：订阅频道（M1，已上线）

---

## 1. 背景与目标

### 1.1 背景
订阅频道此前只承载**小说**（按分类订阅 + 频道内小说货架）。为提升会员价值与内容运营能力，需要让运营能够发布**图文与视频内容**，并挂载到具体订阅频道内供会员浏览/播放。

### 1.2 目标
- 运营在后台以「一条内容」为单位创建图文/视频，**草稿 → 发布 → 下架**全流程可控；
- 发布的内容**仅在对应订阅频道详情页内**展示，与小说统一呈现，不干扰首页；
- 图片与视频由服务端自动压缩/转码，**移动端（Android/iOS）可正常播放**，且受会员订阅鉴权保护；
- 全链路磁盘占用可控，删除内容时**同步清理磁盘文件**。

### 1.3 范围
**包含**：后台内容创作与管理、素材上传压缩/转码、发布挂载、H5 频道内展示与播放、访问控制、防下载、磁盘回收。

**不包含**：
- C 端用户上传（仅后台运营可上传）；
- 富文本正文（内容 = 标题 + 素材）；
- 多频道同时挂载同一条内容；
- 独立的公共素材库（素材随内容归属，不做跨内容复用的素材管理中心）；
- 动图（GIF 动画）播放；水印/DRM 级内容保护。

---

## 2. 角色与权限

| 角色 | 权限 |
|---|---|
| 后台运营 | 上传素材、创建/编辑/删除草稿、发布、下架、在后台预览与播放素材 |
| C 端会员（已订阅/试用中） | 在所属订阅频道内浏览图文、播放视频 |
| C 端未订阅/非 VIP | **不可见**媒体内容（列表不含、字节 403，无预览态） |

## 3. 功能需求

### 3.1 内容创作（后台）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-01 | 新建图文内容 | 标题 + 批量图片（**图片数量不限**） |
| FR-02 | 新建视频内容 | 标题 + 视频（**每帖最多 1 个视频**） |
| FR-03 | 图文 + 视频混合 | 同一条内容可同时包含图片与 1 个视频，类型自动判定为「图文+视频」 |
| FR-04 | **无正文字段** | 内容仅由「标题 + 素材」构成，标题必填（≤120 字） |
| FR-05 | 保存为草稿 | 创建后即为草稿状态，未发布前不影响 C 端 |
| FR-06 | 素材排序与首图 | 图片可调整顺序，**第 1 张即封面**；视频内容以视频封面帧为封面 |
| FR-07 | 素材状态可见 | 转码/压缩处理中、失败状态在编辑器内可见；未就绪素材不可保存/发布 |

### 3.2 内容管理（后台「多媒体池子」）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-08 | 草稿列表 | 列表展示：封面、标题、类型、素材数、挂载频道、更新时间；操作：**新增 / 编辑 / 删除 / 发布** |
| FR-09 | 已发布列表 | 列表展示：封面、标题、类型、挂载频道、发布时间；操作：**仅「下架」**（无删除、无编辑按钮） |
| FR-10 | 发布（挂载频道） | 发布时必须选择挂载频道，进入已发布列表并向 C 端可见 |
| FR-11 | 下架 | 已发布内容下架后**回到草稿列表**，保留所选频道与素材，可再次编辑/发布 |
| FR-12 | 删除规则 | **仅草稿可删除**；已发布内容必须先下架回草稿才能删除（后端强制拒绝直接删除，防止误删线上内容） |
| FR-13 | 后台可播放 | 列表、编辑器、预览中均可**播放视频与查看图片**（运营审核/校对用） |
| FR-14 | 素材预览 | 图片弹层查看原图；视频内联播放器播放 |

### 3.3 发布挂载（与订阅频道的关系）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-15 | 频道数据源 | 发布弹窗的频道列表**来自「订阅频道管理」**，仅状态为**已发布**的频道可选 |
| FR-16 | 已下架频道不可选 | 已下架/未发布频道在弹窗中置灰不可选择 |
| FR-17 | 频道内容统计 | 订阅频道列表的频道卡片展示**该频道内容数量**（小说 + 图文 + 视频） |

### 3.4 H5 展示（C 端）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-18 | 展示位置 | 路径固定为：**[订阅 tab] → [频道列表] → [具体频道] → 内容**；**首页零改动**，媒体内容不出现在首页 |
| FR-19 | 频道内容视图 | 具体频道内为**统一内容网格/列表**，展示该频道的全部内容：**小说 📖 + 图文 🖼 + 视频 ▶ 混排**，按时间倒序 |
| FR-20 | **无 Tab、无分区标题** | 不设置「图文视频/小说」分类 Tab，也不做分区排版（曾评审否决） |
| FR-21 | 网格/列表切换 | 沿用现有「网格 / 列表」切换交互；卡片带类型标识；视频卡显示时长 |
| FR-22 | 点击进入详情 | 图文/视频卡片 → 媒体详情页；小说卡片 → 阅读页（沿用现有行为） |
| FR-23 | 图文详情 | 图集展示（首图放大布局）；图片**常规展示，不做双击放大**（已评审取消） |
| FR-24 | 视频详情 | 原生播放器播放，支持进度拖动、全屏（交系统处理） |
| FR-25 | 已读逻辑 | 已读隐藏**仅作用于小说**（点开即算已读，从列表移除）；**媒体内容不参与已读过滤** |

### 3.5 访问控制与内容保护

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-26 | 订阅鉴权 | 媒体内容**仅订阅用户/试用期内可见**；未订阅用户列表不含媒体、字节请求 403 |
| FR-27 | **无未订阅预览态** | 不为未订阅用户提供「模糊预览/首屏预览」页面 |
| FR-28 | 鉴权流式下发 | 媒体字节经服务端鉴权后流式下发（不暴露静态直链），支持 HTTP Range |
| FR-29 | 防下载 | H5 端图片与视频**禁止用户下载/保存**：禁右键、禁长按、禁拖拽保存、视频禁下载按钮、禁画中画 |

## 4. 素材处理需求

### 4.1 图片

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-30 | 自动压缩 | 上传后服务端自动按比例 + 质量压缩，**成品 ≈1MB**，**不模糊**（清晰度优先保证：长边分辨率下限 1600px、质量下限 75） |
| FR-31 | 缩略图 | 自动生成列表用缩略图（长边 400，约 20–50KB），列表不加载大图 |
| FR-32 | 封面 | 首图自动作为封面 |
| FR-33 | 格式支持 | jpg / jpeg / png / gif / bmp；透明 PNG 合成白底；**GIF 取首帧静态图**；**不支持 WebP**（前端选择时提示） |
| FR-34 | 不保留原图 | 压缩成功后**不保留原图文件**（省空间） |

### 4.2 视频

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-35 | 自动转码 | 服务端统一转码为 **H.264（Main）+ AAC + mp4 + faststart**，确保 **Android 与 iOS 均可播放** |
| FR-36 | 兼容要点 | `yuv420p` 色彩采样；竖拍视频**物理转正**（不依赖旋转元数据）；关键帧间隔 ≤60（保证拖动） |
| FR-37 | 自动封面 | 自动抽取封面帧（避开片头黑场/片尾字幕），生成封面图与缩略图 |
| FR-38 | 规格限制 | 单视频 ≤300MB、时长 ≤15 分钟 |
| FR-39 | 异步处理 | 转码异步执行、低并发，不阻塞上传；失败标记原因并支持重新处理 |
| FR-40 | 每帖 1 个 | 每条内容最多 1 个视频 |

### 4.3 存储与磁盘

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-41 | 存储位置 | 图片与视频存放于 **VPS 服务器自有存储卷**（不依赖第三方对象存储） |
| FR-42 | 去重 | 同一文件（MD5）重复上传时复用已有素材 |
| FR-43 | **删除同步清理磁盘** | 删除内容/移除素材时，**磁盘上的图片与视频同步删除**，不留残留 |
| FR-44 | 兜底清理 | 定时清理孤儿素材、临时中转文件、异常卡死的处理任务 |

**FR-43 的完整触发路径**（需求明确要求）：
1. 草稿列表删除 → 素材无引用则删除记录 + 磁盘文件；
2. 编辑草稿时移除素材并保存 → 被移除素材删除记录 + 文件；
3. 新建内容时移除已选素材 / 取消编辑未保存 → 立即回收该素材；
4. 定时兜底任务 → 回收漏清理的孤儿素材与临时文件。
> 例外：素材仍被其它内容引用时保留（避免破坏其它内容），由兜底任务保证最终不残留。

## 7. 验收标准

1. 后台新增图文/视频 → 草稿列表；发布（选频道）→ 已发布列表 + 频道内可见；下架 → 回草稿并从 C 端消失。
2. 已发布内容**无删除/编辑入口**；后端拒绝删除/编辑已发布内容。
3. 发布弹窗频道列表 = 订阅频道管理中「已发布」频道；已下架频道不可选。
4. 首页与其它现有 H5 页面**零改动**；内容仅在「订阅 → 具体频道」展示；频道内为统一内容网格/列表混排（无 Tab/分区标题）。
5. 图片 ≤1M（±20%）且不模糊；视频 H.264 在 iOS/Android 双端可播放、可拖进度、竖拍方向正确。
6. 同帖视频 ≤1、图片数量不限；同文件二次上传复用素材。
7. **后台可播放**：草稿/已发布/编辑器中均可播放视频、查看图片。
8. **H5 禁下载**：长按/右键/拖拽无法保存图片与视频；视频无下载按钮、无画中画。
9. **风格统一**：后台与 H5 同一品牌色系，无默认蓝与灰蓝黑残留。
10. **素材就绪约束**：视频转码未完成或失败时不可发布；转码完成后正常发布。
11. **未订阅/试用过期**：媒体区不渲染、字节 403；试用期内与已订阅一致。
12. **删除同步清理磁盘**：删除草稿、编辑移除素材、取消未保存素材，磁盘文件均同步删除，无孤儿残留。

## 9. 上线状态与遗留事项

### 9.1 已上线（生产版本 `1e0f693`）
- 后端：素材上传/压缩/转码、内容 CRUD、发布/下架、鉴权流式（Range）、频道统一内容流、兜底清理任务；
- 后台：多媒体池子（草稿/已发布/编辑器/发布弹窗/播放预览）+ 全局墨绿视觉统一；
- H5：频道统一混排网格/列表、图文详情、视频详情、禁下载；
- 部署：数据库迁移、媒体存储卷、ffmpeg 集成、上传大小配置。

### 9.2 生产实测结论
图片压缩、视频转码（25s 内完成，h264/Main/yuv420p/mp4）、Range 206、发布/下架/删除规则、磁盘同步回收、C 端混排 feed、未登录 401 等均已验证通过。

### 9.3 遗留事项
| 项 | 说明 |
|---|---|
| 真机验收 | iOS/Android/微信内实际播放与禁下载表现需人工设备验证 |
| 磁盘容量 | VPS 使用率约 64%，视频持续写入需配套容量监控/告警 |
| 容量看板（可选） | 后台可视化的媒体磁盘用量与素材统计 |
| 清理参数（可选） | 孤儿素材/tmp 保留期目前为配置项，可考虑后台可调 |
| 强度保护（可选） | 水印、DRM、分段加密属后续增强，本期不做 |

## 10. 术语表

| 术语 | 含义 |
|---|---|
| 多媒体池子 | 后台承载图文/视频内容创作与管理的功能模块 |
| 内容帖（Post） | 一条可发布的内容 = 标题 + 有序素材（图片/视频） |
| 素材（Asset） | 单个图片或视频文件及其衍生文件（缩略图、封面帧） |
| 草稿 / 已发布 | 内容两种状态；下架即从已发布回到草稿 |
| 统一内容流（feed） | 频道详情页中小说与媒体内容按时间倒序混排的列表 |
| READY / PROCESSING / FAILED | 素材处理状态：就绪 / 处理中 / 失败 |
